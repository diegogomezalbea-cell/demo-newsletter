# Démo newsletter

Page de démo d'une newsletter pour petites entreprises : formulaire d'inscription et mise en page, en HTML, CSS et JavaScript.

## Lancer le projet

Ouvrir `index.html` dans un navigateur.

## Structure

- `index.html` : la page
- `css/style.css` : les styles
- `js/app.js` : le formulaire d'inscription
